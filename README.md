🎮 Huokaing Thara Gaming - Web Portal

Welcome to the official web portal repository for Huokaing Thara Gaming! This project serves as a sleek, mobile-responsive landing page designed for gaming creators to showcase featured Facebook Reels, live streams, and channel highlights.

✨ Features

🏆 Custom Premium Branding: Styled with dark-blue and gold aesthetic matching the official Huokaing Thara Gaming emblem.

🌐 Dual Language Support: Full Khmer (ភាសាខ្មែរ) and English descriptions tailored for localized and international audiences.

🎬 Interactive Video Preview: Clickable video showcase triggering direct access to the latest Facebook Reel.

📲 Web Share API Integration: Native mobile share popup with interactive clipboard fallback for quick link sharing.

⚡ Lightweight & Responsive: Fully responsive design built with raw HTML5, CSS3, and modern Vanilla JavaScript without external framework bloat.

🛠️ Tech Stack

HTML5: Semantic markup structure.

CSS3: Custom CSS Variables, Flexbox, media queries, and Google Fonts integration (Kantumruy Pro and Poppins).

JavaScript (ES6+): Lightweight interactivity and Web Share API handlers.

Font Awesome: Vector icons for social links and action triggers.

📂 Project Structure

├── index.html     # Main HTML document with bilingual content
├── styles.css     # Custom dark gold themed styling
└── script.js      # Social sharing logic and UI interactions


🚀 Getting Started

Clone the Repository:

git clone https://github.com/your-username/huokaing-thara-gaming.git


Navigate to Project Directory:

cd huokaing-thara-gaming


Run Locally:
Simply open index.html in any web browser of your choice.
